# OMS IT Ownership & Project Relationships

The OMS ecosystem contains different types of projects and initiatives.

Technical development, ownership, operation, and partnership are **not automatically the same thing**.

The following principles are used:

| Relationship | Meaning |
|---|---|
| **OMS IT Product / Project** | A product or project operated/developed as part of OMS IT's own technology work |
| **Engineering / Technology Contribution** | OMS IT provides engineering, technology, AI, infrastructure, or related support |
| **Independent Initiative** | Separate identity with its own organizational positioning |
| **Client / Partner Project** | Project relationship does not automatically transfer ownership to OMS IT |
| **Private Project** | Source code and internal implementation remain private |

No ownership relationship should be inferred solely because a project uses OMS IT technology.
